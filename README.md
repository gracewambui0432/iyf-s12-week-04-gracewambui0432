# Grace Wambui - JavaScript Fundamentals

## Project Overview

This project contains practical exercises completed during Week 4 of the IYF Weekend Academy.

It demonstrates JavaScript fundamentals, functions, conditional statements, loops, arrays, objects, JSON data manipulation, and problem-solving.

## Lessons Covered

### Lesson 7: JavaScript Basics
- Variables and data types
- Arithmetic, comparison and logical operators
- Functions and arrow functions
- Conditional statements
- Loops
- Console calculator

### Lesson 8: Arrays, Objects and Data Manipulation
- Array creation and manipulation
- Array methods
- Objects and object methods
- Arrays of objects
- JSON parsing and stringifying
- Student Grade Tracker

## Mini-Projects

### 1. Calculator
A console-based calculator that supports:
- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Exponentiation

### 2. Student Grade Tracker
An object-based system that can:
- Add students and their subject grades
- Find students
- Calculate student averages
- Calculate subject averages
- Identify the top-performing student
- Identify students with averages below 70
- Assign letter grades
- Generate report cards

## Daily Challenges
1. FizzBuzz
2. Reverse a string
3. Find the largest number
4. Remove duplicate values
5. Check for palindromes

1. Clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server.
4. Open the browser developer tools.
5. Select the Console tab to view the exercise results.
